# Sentiment Analysis Using Ensemble Learning

## Project Overview
Sentiment Analysis Using Ensemble Learning is a machine learning project that analyzes text data and classifies sentiments into three categories: Positive, Negative, and Neutral.

The project uses Natural Language Processing (NLP) techniques and Machine Learning algorithms to identify the sentiment expressed in text.

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Flask
- HTML
- CSS

## Machine Learning Techniques
- Random Forest Classifier
- Word-Level TF-IDF
- Character-Level TF-IDF
- Hybrid Prediction (Rules + Machine Learning)

## Features
- Text sentiment classification
- Positive, Negative, and Neutral predictions
- Text preprocessing using NLP
- Machine learning-based prediction
- Web interface using Flask

## Dataset
The project uses a Twitter sentiment dataset containing text samples with different sentiment labels.

## How to Run the Project

1. Clone the repository.
2. Install the required packages.
3. Run the Flask application.

```bash
pip install -r requirements.txt
python app.py
```

Open the local URL displayed in the terminal.

## Output
The application predicts one of three sentiment categories:
- Positive
- Negative
- Neutral
